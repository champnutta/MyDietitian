## คู่มือ Flex แบบใหม่

เมื่อพิมพ์ `คู่มือ` ระบบจะแสดง carousel 4 การ์ดใน visual language เดียวกับ MyDietitian แทนหัวการ์ดหลายสีแบบเดิม:

1. **บันทึกมื้อให้แม่น** — บันทึกอาหาร จัดการเฉพาะมื้อ และตรวจสอบก่อนบันทึก
2. **ร่างกายและกิจกรรม** — ออกกำลังกาย น้ำหนัก และรายงาน BIA
3. **ติดตามความคืบหน้า** — สรุปวันนี้ Dashboard และเป้าหมาย/CUT/Bulk
4. **โค้ชและความช่วยเหลือ** — โค้ช AI วันใช้งาน และการติดต่อทีมงาน

แต่ละการ์ดใช้หัวสีเขียวเข้ม พื้นข้อมูลสีอ่อน ลำดับขั้นชัดเจน และมีปุ่มสำหรับ action หลัก เพื่อลดการจำคำสั่ง

## คู่มือผู้ใช้ฉบับย่อ

### 1. บันทึกอาหาร

แตะ “บันทึกอาหาร” เพื่อถ่ายรูป หรือพิมพ์ชื่ออาหารในแชต ระบบจะวิเคราะห์และส่งการ์ดผลลัพธ์พร้อมแคลอรี่ สารอาหาร คะแนนสุขภาพ และยอดสะสมวันนี้

### 2. แก้ผลประเมิน หักของเหลือ หรือลบ

ทำจากปุ่มใต้การ์ดของมื้อนั้น:

- “แก้ผลประเมิน” เลือกปริมาณที่กินจริง หรือแก้ชนิด/ส่วนประกอบอาหาร
- “หักของเหลือ” ถ่ายรูปของเหลือ ตรวจผลประเมิน แล้วกดยืนยัน
- “ลบมื้อนี้” ตรวจชื่อและสารอาหาร แล้วกดยืนยันลบ

ทุก action ผูกกับมื้อที่เลือกและมีขั้นตอนยืนยัน ไม่ควรใช้ปุ่มกล้องลอย ๆ เพื่อหักของเหลือ

### 3. ดูสรุปและแดชบอร์ด

- แตะ “สรุปวันนี้” เพื่อดูแคลอรี่ สารอาหาร มื้อที่บันทึก โปรแกรมรายสัปดาห์ และทางลัดโค้ช
- แตะ “แดชบอร์ด” เพื่อดูกราฟ ประวัติอาหาร การออกกำลังกาย และน้ำหนัก
- ลิงก์แดชบอร์ดเป็นลิงก์ส่วนตัว อายุ 1 ชั่วโมง หากหมดอายุให้แตะ Rich menu หรือพิมพ์ `กราฟ` เพื่อขอลิงก์ใหม่

### 4. ตั้งค่าเป้าหมายและโปรแกรม

แตะ “ตั้งค่าเป้าหมาย” เพื่อแก้ TDEE และสัดส่วนสารอาหาร หรือสร้างโปรแกรม CUT/Bulk ที่ปรับเป้าหมายทีละสัปดาห์ ระบบรองรับการเริ่มปรับตั้งแต่สัปดาห์แรกและยกเลิกโปรแกรมเพื่อกลับไปใช้เป้าหมายหลัก

### 5. ใช้โค้ช AI และบันทึกกิจกรรม

- แตะ “โค้ช AI” หรือพิมพ์ `กินอะไรดี` เพื่อขอเมนูตามยอดและเป้าหมายวันนี้
- ถามคำถามด้านอาหารได้โดยพิมพ์เป็นประโยค เช่น `ดึกแล้วกินอะไรดี`
- บันทึกการออกกำลังกาย เช่น `วิ่ง 30 นาที`
- จดน้ำหนัก เช่น `หนัก 65 fat 20 muscle 28`

### 6. ติดต่อทีมงาน

1. พิมพ์ `แอดมิน` ตามด้วยข้อความ เช่น `แอดมิน ขอเปลี่ยนวันเริ่ม`
2. ระบบเปิดเคสและส่งข้อความเข้า **Admin Dashboard > ข้อความลูกค้า**
3. เมื่อทีมงานตอบ ลูกค้าจะได้รับการ์ดตอบกลับใน LINE พร้อมปุ่ม **“ตอบแอดมิน”**
4. แตะปุ่มแล้วส่งข้อความถัดไป 1 ข้อความภายใน 10 นาที ระบบจะส่งเข้าเคสเดิม
5. หลังส่งหนึ่งครั้ง ข้อความถัดไปจะกลับไปเป็นคำสั่งหรือข้อมูลอาหารตามปกติ จึงไม่เกิดโหมดสนทนาค้าง
6. หากไม่ต้องการตอบแล้ว พิมพ์ `ยกเลิกตอบแอดมิน`

ทีมงานอ่าน ตอบ และปิดเคสจากหน้า Admin Web ได้โดยไม่ต้องใช้คำสั่ง `คุย`, `จบ` หรือจำ LINE User ID อีกต่อไป

## คู่มือสำหรับแอดมิน: Support Inbox

- เปิด `https://mydietitian.web.app/admin#support` แล้วเข้าสู่ระบบด้วยบัญชีแอดมิน
- badge ที่แท็บ “ข้อความ” แสดงจำนวนเคสที่เปิดอยู่
- กรองได้ตาม **รอทีมงานตอบ**, **รอลูกค้าตอบ**, **ปิดแล้ว** หรือทั้งหมด
- เลือกเคสเพื่ออ่าน thread แล้วพิมพ์คำตอบ ระบบส่ง Flex message กลับ LINE ของลูกค้า
- กด **ปิดเคส** เมื่อจบเรื่อง ลูกค้าจะได้รับข้อความแจ้งและสามารถพิมพ์ `แอดมิน <ข้อความ>` เพื่อเปิดเคสใหม่ได้

## ตรวจสอบและเผยแพร่

ตรวจไฟล์โดยไม่เปลี่ยน Rich menu:

```powershell
node tools\publish_rich_menu.js
```

สร้าง Rich menu ใหม่ อัปโหลดภาพ และตั้งเป็นค่าเริ่มต้น:

```powershell
$env:LINE_CHANNEL_ACCESS_TOKEN = "<channel access token>"
node tools\publish_rich_menu.js --publish
```

สคริปต์จะไม่ลบ Rich menu เดิม เพื่อให้ย้อนกลับได้จาก LINE Official Account Manager
