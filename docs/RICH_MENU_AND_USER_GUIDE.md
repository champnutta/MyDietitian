ปุ่ม “บันทึกอาหารที่กินเหลือ” เดิมถูกถอดออก เพราะ flow ใหม่ต้องเริ่มจากการ์ดของมื้อที่ต้องการแก้ เพื่อป้องกันการหักผิดมื้อ

## คู่มือผู้ใช้ฉบับย่อ

### 1. บันทึกอาหาร

แตะ “บันทึกอาหาร” เพื่อถ่ายรูป หรือพิมพ์ชื่ออาหารในแชต ระบบจะวิเคราะห์และส่งการ์ดผลลัพธ์พร้อมแคลอรี่ สารอาหาร คะแนนสุขภาพ และยอดสะสมวันนี้

### 2. แก้ผลประเมิน หักของเหลือ หรือลบ

ทำจากปุ่มใต้การ์ดของมื้อนั้น:

- “แก้ผลประเมิน” เลือกปริมาณที่กินจริง หรือแก้ชนิด/ส่วนประกอบอาหาร
- “หักของเหลือ” ถ่ายรูปของเหลือ ตรวจผลประเมิน แล้วกดยืนยัน
- “ลบมื้อนี้” ตรวจชื่อและสารอาหาร แล้วกดยืนยันลบ

ทุก action ผูกกับมื้อที่เลือกและมีขั้นตอนยืนยัน ไม่ควรใช้ปุ่มกล้องลอย ๆ เพื่อหักของเหลือ

### 3. ดูสรุปและแดชบอร์ด

- แตะ “สรุปวันนี้” เพื่อดูแคลอรี่ สารอาหาร มื้อที่บันทึก โปรแกรมรายสัปดาห์ และทางลัดโค้ช
- แตะ “แดชบอร์ด” เพื่อดูกราฟ ประวัติอาหาร การออกกำลังกาย และน้ำหนัก
- ลิงก์แดชบอร์ดเป็นลิงก์ส่วนตัว อายุ 1 ชั่วโมง หากหมดอายุให้แตะ Rich menu หรือพิมพ์ `กราฟ` เพื่อขอลิงก์ใหม่

### 4. ตั้งค่าเป้าหมายและโปรแกรม

แตะ “ตั้งค่าเป้าหมาย” เพื่อแก้ TDEE และสัดส่วนสารอาหาร หรือสร้างโปรแกรม CUT/Bulk ที่ปรับเป้าหมายทีละสัปดาห์ ระบบรองรับการเริ่มปรับตั้งแต่สัปดาห์แรกและยกเลิกโปรแกรมเพื่อกลับไปใช้เป้าหมายหลัก

### 5. ใช้โค้ช AI และบันทึกกิจกรรม

- แตะ “โค้ช AI” หรือพิมพ์ `กินอะไรดี` เพื่อขอเมนูตามยอดและเป้าหมายวันนี้
- ถามคำถามด้านอาหารได้โดยพิมพ์เป็นประโยค เช่น `ดึกแล้วกินอะไรดี`
- บันทึกการออกกำลังกาย เช่น `วิ่ง 30 นาที`
- จดน้ำหนัก เช่น `หนัก 65 fat 20 muscle 28`
- ติดต่อผู้ดูแลด้วย `แอดมิน` ตามด้วยข้อความ

## ตรวจสอบและเผยแพร่

ตรวจไฟล์โดยไม่เปลี่ยน Rich menu:

```powershell
node tools\publish_rich_menu.js
```

สร้าง Rich menu ใหม่ อัปโหลดภาพ และตั้งเป็นค่าเริ่มต้น:

```powershell
$env:LINE_CHANNEL_ACCESS_TOKEN = "<channel access token>"
node tools\publish_rich_menu.js --publish
```

สคริปต์จะไม่ลบ Rich menu เดิม เพื่อให้ย้อนกลับได้จาก LINE Official Account Manager
